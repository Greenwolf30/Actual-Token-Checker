## Ledger multi-chain (short)

1. **Solana app** → Connect Ledger  
2. **Ethereum app** → Link EVM (or pick ETH/Polygon/Base — auto-links)  
3. Opening an app on the Nano alone does **not** connect — Gladiator must read the address  
4. Bitcoin & Sui Ledger are **not** supported yet
