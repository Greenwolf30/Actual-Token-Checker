Gladiator Wallet — load as unpacked Chrome/Opera extension

1. chrome://extensions → Developer mode ON
2. Load unpacked → select THIS folder
3. Click Reload on Gladiator
4. Click the Gladiator toolbar icon once (popup) so keys sync
5. Use Jupiter — no side window needed
