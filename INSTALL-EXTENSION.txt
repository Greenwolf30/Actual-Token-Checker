Gladiator Wallet — update without losing your wallet

PREFERRED UPDATE (keeps seed / accounts):
1. Unzip the new pack
2. Copy everything INSIDE the new folder into your EXISTING Gladiator folder (overwrite)
3. chrome://extensions → Gladiator → Reload (do NOT Remove)
4. If Chrome asks for HID / Ledger permission, Allow
5. Click the toolbar icon once

Uniswap:
1. Use a seed wallet (needs EVM key — Ledger-only accounts have no EVM key yet)
2. Open app.uniswap.org → Connect → choose Gladiator
3. Approve eth_requestAccounts; switch Ethereum/Base/Polygon in Uniswap as needed

Ledger:
1. Unlock Nano → open Solana app
2. Open Gladiator → Wallets → Ledger → Connect Ledger
3. Pick the device in the browser HID prompt and approve
