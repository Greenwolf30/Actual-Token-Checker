Gladiator Wallet — load as unpacked Chrome/Opera extension

1. chrome://extensions → REMOVE old Gladiator → Load unpacked → THIS folder
2. Click Reload
3. Click the Gladiator TOOLBAR ICON once
4. Wait for toast: “Jupiter signing ready”
5. Hard-refresh jup.ag → Connect → swap
