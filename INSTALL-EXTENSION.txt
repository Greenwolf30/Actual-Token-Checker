Gladiator Wallet — load as unpacked Chrome/Opera extension

1. chrome://extensions → Developer mode ON
2. Load unpacked → select THIS folder (Gladiator-Wallet-Extension)
3. Do NOT load a folder that contains __pycache__ or serve.py

WalletConnect / Jupiter:
- Paste Reown Project ID + wc: URI → Connect
- A "Session relay" window opens — KEEP IT OPEN while swapping on Jupiter
- Toolbar popup closes when you leave it; the relay window receives swap confirms

If you previously set a wallet password: open Gladiator once and enter it to restore keys
(encryption is paused for now).
