Gladiator Wallet — Chrome / Opera extension (v0.5.25)

IMPORTANT — __pycache__ error:
Opera/Chrome cannot load a folder that contains __pycache__.
If you unzip over your old Desktop\Gladiator-Wallet (the one used with serve.py),
that old __pycache__ folder stays and Load unpacked fails.

Fix (pick one):
A) Delete the whole Desktop\Gladiator-Wallet folder, then unzip this zip fresh.
B) Or double-click DELETE-PYCACHE.bat inside Gladiator-Wallet, then Reload.

Load:
1. Unzip → you should get a Gladiator-Wallet folder with manifest.json inside it.
2. opera://extensions (or chrome://extensions) → Developer mode → Remove old Gladiator.
3. Load unpacked → select that Gladiator-Wallet folder (the one that contains manifest.json).

WalletConnect (pump.fun):
1. Free Project ID: https://cloud.reown.com
2. Gladiator → ⋮ → WalletConnect
3. Paste Project ID + a fresh wc: URI from pump.fun
4. Keep the popup open while connecting / signing
