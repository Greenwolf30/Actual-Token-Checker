Gladiator Wallet — load as unpacked Chrome/Opera extension

1. chrome://extensions → Developer mode ON
2. Remove any OLD Gladiator entry, then Load unpacked → THIS folder
3. Click Reload
4. Click the Gladiator toolbar icon once (popup must open)
5. If asked for old password, enter it — or import seed/secret key
6. Hard-refresh jup.ag → Connect Gladiator → swap
