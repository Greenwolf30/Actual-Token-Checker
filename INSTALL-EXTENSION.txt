Gladiator Wallet — load as unpacked Chrome/Opera extension

1. chrome://extensions → Developer mode ON
2. Load unpacked → select THIS folder (Gladiator-Wallet-Extension)
3. Reload the extension after updates (manifest version must change)

v0.5.51:
- Fix “No Solana key” on Jupiter swaps
- If signing keys are missing/locked, Gladiator opens a restore prompt
- Re-derives Solana secret from seed phrase when present

IMPORTANT if swaps fail with “No Solana key”:
1. Open the Gladiator wallet window
2. If asked for your old password — enter it once (restores keys)
3. Or Settings → import your seed phrase / Solana secret key
4. Retry the Jupiter swap
