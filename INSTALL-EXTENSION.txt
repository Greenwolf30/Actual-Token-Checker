Gladiator Wallet — load as unpacked Chrome/Opera extension

1. Unzip → open the Gladiator-Wallet-0.5.57 folder
2. chrome://extensions → REMOVE old Gladiator → Load unpacked → that folder
3. Click Reload
4. Click the Gladiator TOOLBAR ICON once
5. Wait for toast: “Jupiter signing ready”
6. Hard-refresh jup.ag → Connect → swap
