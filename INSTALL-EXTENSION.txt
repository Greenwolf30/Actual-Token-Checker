Gladiator Wallet — Chrome / Opera extension

CRITICAL — do NOT load your old Desktop\Gladiator-Wallet folder if it has
Python files (__pycache__). Chrome/Opera will refuse it:

  "Cannot load extension with file or directory name __pycache__"

Use the folder named:  Gladiator-Wallet-Extension
(that folder has manifest.json and NO serve.py / NO __pycache__)

If you must reuse Desktop\Gladiator-Wallet:
1. Double-click DELETE-PYCACHE.bat inside it
2. Or delete the __pycache__ folder manually
3. Then Reload the extension

Load steps:
1. Unzip this download
2. opera://extensions (or chrome://extensions) → Developer mode ON
3. Remove any old Gladiator extension
4. Load unpacked → select Gladiator-Wallet-Extension
   (the folder that contains manifest.json)

WalletConnect (pump.fun):
1. Free Project ID: https://dashboard.walletconnect.com
2. Gladiator → ⋮ → WalletConnect
3. Paste Project ID + a fresh wc: URI from pump.fun → Connect
4. Active sessions appear under Connections (Disconnect anytime)
